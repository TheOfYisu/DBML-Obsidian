# Security Policy

## Supported Versions

We actively release security updates and bug fixes for the current major version of the plugin.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of this Obsidian plugin seriously. If you discover a security vulnerability, please follow the process below to report it responsibly.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues. 

Instead, report them privately using one of the following options:

1. **GitHub Private Vulnerability Reporting:** Go to the **Security** tab of this repository → **Advisories** → Click **"Report a vulnerability"**.
2. **Direct Contact:** Send an email or private message to **Jesús Daniel Garizao Mejía** ([@TheOfYisu](https://github.com/TheOfYisu)).

### What to Include in Your Report

To help us understand and fix the issue faster, please include:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions (or a proof-of-concept payload/diagram code) to reproduce the issue.
- Your Obsidian version and OS environment details.

### What to Expect

- **Acknowledgment:** We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment:** We will investigate and provide a status update on whether the vulnerability is confirmed within **5 business days**.
- **Fix & Disclosure:** Once a fix is prepared, we will release a new patch version and coordinate a public disclosure if necessary.
